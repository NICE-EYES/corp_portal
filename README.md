# Портал сотрудников ООО «НоваТех»

Корпоративный веб-портал для сотрудников компании: новости, справочник сотрудников, подача и обработка заявок (отпуск, отгул, командировка, справка), а также администрирование пользователей.

## Технологии

- PHP 7.4+ (PDO)
- MySQL / MariaDB
- HTML, CSS (без фреймворков)

## Возможности

### Для всех посетителей
- Просмотр новостей компании на главной странице
- Регистрация — новая учётная запись становится активной только после одобрения администратором

### Сотрудник (`employee`)
- Справочник сотрудников с поиском по ФИО, должности и отделу
- Подача заявок: отпуск, отгул, командировка, справка с места работы
- Просмотр своих заявок и их статусов (новая / одобрена / отклонена)

### Руководитель (`manager`)
- Всё, что доступно сотруднику
- Обработка заявок сотрудников (одобрение / отклонение)
- Публикация и удаление новостей

### Администратор (`admin`)
- Всё, что доступно руководителю
- Подтверждение или отклонение новых регистраций
- Управление пользователями: добавление, редактирование, удаление, назначение ролей

## База данных

| Таблица    | Назначение                                                        |
|------------|-------------------------------------------------------------------|
| `users`    | Пользователи: логин, хеш пароля, ФИО, должность, отдел, контакты, роль, признак одобрения |
| `news`     | Новости: заголовок, текст, автор, дата                            |
| `requests` | Заявки сотрудников: тип, период, комментарий, статус              |

## Установка и запуск

1. Скопируйте проект в каталог веб-сервера (например, `htdocs` в XAMPP или `www` в OpenServer).
2. Создайте базу данных и импортируйте дамп:
   ```bash
   mysql -u root -p -e "CREATE DATABASE corp_portal CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
   ```
   ```bash
   mysql -u root -p corp_portal < database.sql
   ```
3. При необходимости укажите свои параметры подключения в `includes/config.php`:
   ```php
   $host = 'localhost';
   $dbname = 'corp_portal';
   $username = 'root';
   $password = '';
   ```
4. Откройте в браузере `http://localhost/corp_portal/`.

## Безопасность

- Пароли хранятся в виде хеша (`password_hash` / `password_verify`)
- Все запросы к БД выполняются через подготовленные выражения PDO
- Вывод данных экранируется через `htmlspecialchars` (защита от XSS)
- Доступ к страницам ограничен по ролям
